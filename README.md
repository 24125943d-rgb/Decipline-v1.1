# Decipline v1.1

基于 **Godot 4.7.2** 的角色行为与可视化积木编程实验项目。通过组合角色能力、编辑积木程序，让角色读取环境信息并执行攻击、追逐等指令。

## 项目构成

- **角色与属性**：基础角色、外观与碰撞体、生命/精神状态，以及属性和临时修正表。立场取 `-1 / 0 / 1`，双方乘积决定敌对、友方或中立关系。
- **能力组件**：移动、攻击、视野与 Decipline 分开装配。攻击包含冷却与状态检查；追逐支持取消、超时和受阻退出，目前采用直线移动，不提供自动寻路。
- **范围与接触**：可复用的圆形、扇形、矩形范围资源及可视化。几何包含与视线遮挡分离；`attach` 判定实体碰撞体是否接触或邻接。
- **BlockSystem**：包含 AST 数据结构、积木 UI、拖放插槽、序列化和编译器，支持条件、循环、嵌套表达式及对象参数。
- **角色程序接口**：通过统一接口定义检查 `Enemy.visible.closest`、`Attack-range`、`Attack`、`Chase` 等查询与指令。Decipline 将积木编译为独立执行器，通过角色宿主下达指令，**不替换角色本身的脚本**。
- **自动化测试**：覆盖属性、视野、范围、战斗、积木往返、编译及执行生命周期。最近一次完整回归为 **231 项通过**；自动化结果不代表所有交互都已完成实玩验收。

## 目录

| 路径 | 内容 |
| --- | --- |
| `BlockSystem/Core/` | AST、类型与语法规则 |
| `BlockSystem/Logic/` | 积木交互、同步与编译 |
| `BlockSystem/Art/`、`BlockSystem/Prefabs/` | 主题、样式与积木预制体 |
| `scripts/` | 角色、能力组件、程序接口与场景逻辑 |
| `scenes/` | 角色预制体及实验场景 |
| `data/` | 属性修正等数据资源 |
| `tests/` | GDScript 自动化测试 |
| `PROJECT_GOALS.md` | 工程目标与角色程序使用说明 |

## 运行

1. 使用 Godot **4.7.2** 导入仓库根目录的 `project.godot`。
2. 等待资源导入完成。
3. 打开下面任一场景，按 **F6** 运行当前场景：

| 场景 | 用途 |
| --- | --- |
| `scenes/block_lab.tscn` | 查看与编辑测试积木程序 |
| `scenes/vision_trial.tscn` | 视野、遮挡及范围显示实验 |
| `scenes/stance_trial.tscn` | 立场与积木驱动的战斗实验 |
| `scenes/character_lab.tscn` | 基础角色实验 |

在 `stance_trial` 中，A/B/C 立场为 `1`，D/E/F/G 为 `-1`。只有 A/B/C 执行测试积木：A/C 追逐至实体接触，B 追逐至攻击范围；D–G 不执行积木程序。没有可见敌人时，当前测试程序退出，不自动重启。

> `addons/ziva_agent/`、Godot 缓存及本地凭据不随仓库分发；运行游戏无需这些编辑器工具。小鼠模型约 53 MB，首次克隆与导入可能需要一些时间。
